
# Plant Disease Detection

An image classification project using PyTorch and the PlantVillage dataset.

## Technologies

- Python 3.14.3
- PyTorch
- Torchvision
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Gradio

## Project Objective

To classify plant leaf images into healthy and diseased categories using deep learning.

## Deployment

The application will be deployed using Hugging Face Spaces.
